# 猫咪小院 · 像素流浪猫物语

手机优先的像素猫咪布置游戏：15 种道具、8 种猫咪、3 张大地图、任务金币、触屏拖动和双指缩放。新增“小猫养成”横版互动屋，可点击摸摸、按住拖拽、喂食、陪玩和切换场景；养成进度保存在本机浏览器。单机无需安装依赖，进度保存在本机浏览器。

## 本地游玩

主页 `index.html` 依赖同目录的 `style.css`、`game.js`、`pet.js` 和 `online.js`。在文件模式下部分浏览器会限制 ES Module；建议通过静态 HTTP 服务器或 GitHub Pages 打开。

## 小猫对话

在“小猫养成”中点击“加载本地模型”后，可使用浏览器内的 Qwen2.5 0.5B 小模型和奶糖对话。模型文件由本站提供，聊天内容只在设备上的 WebGPU worker 中处理，不调用豆包、云端聊天 API，也不按消息收费。首次下载约 300 MB，模型加载后可离线生成回复；需要支持 WebGPU 的浏览器和足够的设备内存。

独立的 `catyard-pet-chat-v1` 本地存档只保留最近 30 条消息；“清空聊天”不改变养成状态。养成存档继续使用 `catyard-pet-v1`。模型缓存可清除，无法使用 WebGPU 时会明确提示且保留原有养成功能。手机软键盘打开时根据可视区域调整弹层高度，输入框可滚动到可见位置。

回归测试：通过 `NODE_PATH` 指定 Playwright 后运行 `node tests/pet-chat.cjs`；该测试覆盖本地模型 worker 生命周期协议、动作限制、触摸拖拽、中文输入法、存档和桌面/手机横竖屏/缩小可视区域布局。另用支持 WebGPU 的 Chrome 做过真实模型加载和生成验证；真实 iOS/Android 软键盘仍建议在设备上验收。

## 好友联机

线上版本使用 PeerJS 建立点对点数据连接，不需要填写 Firebase 配置。点击“创建 / 加入房间”，房主把 8 位房间码发给好友，好友输入后即可共享三张地图、摆放物、猫咪状态和视角；金币与任务仍按各自玩家计算。房主离开后房间会结束，好友重新打开页面即可继续单机游玩。

## 发布到 GitHub Pages

将网站文件、`local-model.js`、`local-model-worker.js`、`vendor/webllm` 和 `models/qwen2.5-0.5b` 一起放到仓库根目录；之后在 **Settings → Pages** 选择 `main` 分支和 `/(root)`。本地模型首次下载约 300 MB，建议在 Wi-Fi 下加载；若设备不支持 WebGPU，地图、养成和原有单机功能仍可使用。更新养成资源时同步修改 HTML 内的版本参数，避免客户端混用旧脚本或样式。
