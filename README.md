# 喵呜小屋 · 像素猫咪游戏

无需构建步骤的静态网页游戏，主页是 `index.html`。可以投喂猫粮、照顾猫咪状态、玩抓鱼小游戏赚金币，并切换不同猫咪。

## 发布到 GitHub Pages

1. 在 GitHub 新建仓库。
2. 上传 `index.html` 和 `.nojekyll` 到仓库根目录。
3. 打开 **Settings → Pages**，选择 **Deploy from a branch**。
4. 选择 `main` 分支和 `/(root)` 文件夹并保存。
5. 发布完成后，从 Pages 设置页打开网站地址。

提醒：使用 GitHub Free 时，Pages 站点需要放在公开仓库中，任何人都可以访问。
